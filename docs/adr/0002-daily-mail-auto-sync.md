# Mail is auto-synced once every 24 hours; no other Graph polling

The app previously called Microsoft Graph only on explicit user action. We now also sync mail automatically, once per 24 hours, from the worker, so Notifications are fresh without opening Settings. The schedule is the persisted last-success and last-attempt times (`MailSyncState.lastSuccessAt` / `lastAttemptAt`) checked on an hourly tick (never a sleep loop, so restarts cannot cause extra runs); failures are recorded and not retried until the next window; a dead refresh token halts auto-sync until the student reconnects Microsoft. Each sync is one Graph call for the 25 newest messages. Anything more frequent, or any webhook, is out of scope: webhooks would need a public endpoint (see ADR-0003).
